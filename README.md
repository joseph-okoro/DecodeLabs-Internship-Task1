# 🧹 Data Cleaning Project — DecodeLab Data Analytics Internship

**Author:** Joseph Okoro  
**Program:** DecodeLab Data Analytics Internship — Project 1

## 📌 Overview
This project involved auditing a 1,200-row e-commerce order dataset to assess and improve data quality, as the first deliverable in the DecodeLab internship program.

## 🔍 Process
- Reviewed all 14 columns for missing values, invalid formats, and inconsistencies
- Confirmed the dataset was largely clean and well-structured
- Identified 309 blank `CouponCode` entries and replaced them with `"No Coupon"` for clarity and consistency
- Verified data types, date formats, and column integrity across all records

- `Cleaned Data.xlsx` — contains **Raw Data** and **Cleaned Data** tabs
